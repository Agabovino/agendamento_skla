Política de Privacidade

Última atualização: 22 de setembro de 2026

A SKLA Vídeo ("nós", "nosso" ou "aplicação"), acessível através do endereço agendamento.skla.video, valoriza e respeita a privacidade de seus usuários e clientes. Esta Política de Privacidade explica de forma transparente como coletamos, usamos, armazenamos, tratamos e protegemos seus dados pessoais em total conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018) e com as diretrizes de proteção de dados das plataformas parceiras, incluindo o Google.

1. Sobre a Aplicação

A plataforma agendamento.skla.video é um sistema web dedicado ao agendamento de horários para sessões de gravação, produções audiovisuais, podcasts e consultorias com a equipe da SKLA Vídeo.

2. Dados Coletados

Para a prestação do serviço de agendamento, coletamos exclusivamente as seguintes informações:

  • Dados fornecidos diretamente pelo cliente ao agendar: Nome completo, endereço de e-mail, número de WhatsApp/telefone, data e horário selecionados, e eventuais anotações sobre o serviço desejado.
  • Dados de acesso técnico: Endereço IP, tipo de navegador, registros de requisição (logs técnicos estritamente necessários para a segurança e estabilidade da infraestrutura).

3. Integração com a API do Google (Google Calendar)

Para garantir que os agendamentos sejam sincronizados em tempo real e evitar conflitos de horários, a aplicação integra-se à Google Calendar API por meio do protocolo seguro OAuth 2.0.

Google OAuth Declaração de Acesso e Uso de Dados do Google

Escopos Solicitados: https://www.googleapis.com/auth/calendar.events (ou calendar.events.readonly para consulta e calendar.events para inserção de agendamentos).

Como acessamos: A conexão é estabelecida mediante consentimento expresso do administrador e da equipe responsável da SKLA via tela de autorização oficial do Google OAuth.

Finalidade exclusiva: Os dados de calendário são acessados exclusivamente para:

  1. Verificação de Disponibilidade: Ler a lista de eventos de calendário existentes na agenda da SKLA para identificar horários ocupados e calcular os blocos de horário livres exibidos ao público no site.
  2. Inserção do Agendamento: Criar automaticamente um novo evento no Google Calendar contendo os detalhes do serviço agendado pelo cliente quando uma reserva for confirmada.

Nenhum evento pessoal é lido, transmitido ou compartilhado publicamente: O sistema apenas verifica se determinado bloco de tempo está ocupado ou livre, não divulgando títulos, descrições ou participantes de outros compromissos previamente agendados na conta do Google.

Conformidade com a Política de Dados do Usuário dos Serviços de API do Google

O uso e a transferência para qualquer outro aplicativo de informações recebidas das APIs do Google cumprirão a Política de Dados do Usuário dos Serviços de API do Google , incluindo os requisitos de Uso Limitado (Limited Use Requirements).

Não Venda e Não Compartilhamento: Nós NÃO vendemos, não alugamos, não comercializamos e não transferimos dados obtidos através da API do Google Calendar para terceiros, corretores de dados, empresas de publicidade ou ferramentas de marketing.

Não Utilização para Inteligência Artificial: Os dados obtidos via Google Calendar NÃO são utilizados para alimentar, treinar ou aprimorar modelos de linguagem (LLMs) ou algoritmos de inteligência artificial generativa.

4. Armazenamento e Segurança dos Dados

A segurança dos seus dados é prioritária. Adotamos padrões técnicos robustos para resguardar as informações:

  • Criptografia em Repouso: Tokens de acesso OAuth (Access Token e Refresh Token) são salvos no banco de dados de maneira fortemente criptografada utilizando algoritmo AES-256.
  • Criptografia em Trânsito: Toda a comunicação entre o seu navegador, o servidor da aplicação e as APIs do Google é transmitida via protocolo criptografado HTTPS / TLS.
  • Controle de Acesso Restrito: Somente administradores autenticados com credenciais seguras têm permissão para configurar a integração com o Google Calendar.

5. Retenção e Exclusão de Dados

Os dados de agendamento são mantidos apenas pelo período necessário para a realização da sessão agendada e eventual histórico administrativo/financeiro.

Exclusão de Dados e Desconexão do Google:

  • O administrador pode desconectar a conta do Google a qualquer momento através do painel de administração da plataforma, o que resulta na imediata exclusão dos tokens de acesso e autorizações armazenadas em nosso banco de dados.
  • O usuário também pode revogar o acesso do aplicativo diretamente a qualquer momento através das configurações de segurança de sua Conta Google em myaccount.google.com/permissions.
  • Clientes que desejarem a exclusão de seus registros de agendamento podem solicitar a qualquer momento através do nosso e-mail de contato.

6. Bases Legais para o Tratamento (LGPD - Art. 7º)

O tratamento de dados pessoais pela SKLA Vídeo baseia-se nas seguintes hipóteses legais previstas pela LGPD:

  • Execução de Contrato ou Procedimentos Preliminares (Art. 7º, V): Para viabilizar a reserva e a realização da sessão de gravação solicitada.
  • Consentimento do Titular (Art. 7º, I): Mediante a autorização explícita do fluxo OAuth para integração de agendas.
  • Legítimo Interesse (Art. 7º, IX): Para aprimoramento da segurança, prevenção de fraudes e bom funcionamento do sistema.

7. Direitos do Titular dos Dados

Em conformidade com o Artigo 18 da LGPD, você possui o direito de, a qualquer momento e mediante requisição:

  • Confirmar a existência de tratamento de seus dados;
  • Acessar os dados que possuímos sobre você;
  • Solicitar a correção de dados incompletos, inexatos ou desatualizados;
  • Solicitar a eliminação dos dados pessoais tratados;
  • Revogar o seu consentimento de forma simples e gratuita.

8. Compartilhamento com Terceiros

Seus dados pessoais não são compartilhados com terceiros, exceto com os provedores estritamente necessários para a operação técnica da plataforma (como serviços de hospedagem em nuvem e banco de dados que operam sob rigorosos acordos de confidencialidade e segurança) ou mediante obrigação legal.
